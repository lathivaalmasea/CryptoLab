# CryptoLab

Aplikasi pembelajaran enkripsi dan dekripsi untuk proyek Mata Kuliah Kriptografi.

## Menu
1. Caesar Cipher — klasik
2. Vigenère Cipher — klasik
3. XOR Cipher — modern
4. LFSR Stream Cipher — modern
5. Super Encryption — gabungan 4 algoritma

## Teknologi
- Python
- Streamlit
- Pandas

## Menjalankan di komputer

```bash
git clone URL_REPOSITORY
cd cryptolab
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

Linux/macOS:
```bash
source .venv/bin/activate
```

Install library:
```bash
pip install -r requirements.txt
```

Jalankan:
```bash
streamlit run app.py
```

## Catatan
Versi ini adalah fondasi awal proyek. Algoritma, UI, validasi, pengujian, dan dokumentasi masih dapat dikembangkan bersama.
